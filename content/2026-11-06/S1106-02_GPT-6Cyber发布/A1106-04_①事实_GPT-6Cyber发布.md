【正文】
2026 年 11 月 5 日，OpenAI 发布 GPT-6 Cyber。官方给出的第一个数字是 ExploitGym 48.5%，上一代 GPT-5.6 Cyber 是 32.1%。

48.5% 这个数，官方自己的说法是"比上一代高约 16 个百分点，相对提升 51%"。两个数都对，一个是绝对差，一个是相对涨幅。它测的只有一件事：给一个已知漏洞和触发它的输入，你能不能做出真正打通、读到 flag 的利用。

不是通用模型的加强版

系统卡第一句写得很直白：GPT-6 Cyber 是 GPT-6 Astra 的网络安全专用变体，为"授权范围内的安全工作"训练。后训练走强化学习，任务包括复现崩溃、开发可用利用、在代码库里检索漏洞。另外加了一条奖励信号，专门用来降低它对授权内安全请求的拒答率。

它被训练成"少说不"。安全场景里这是刚需：研究员要的是能跑起来的利用，不是一段免责声明。

三个基准，三种难度

ExploitGym 是第一个。48.5%，比上一代高 16 个百分点。

RemoteExploitBench 是这次新造的，靶子是 GitLab、PostgreSQL、Jenkins 的已知漏洞，部署在受控环境里。GPT-6 Cyber 完成 95%。对照组 GPT-6 Astra 在 Daybreak Blue 配置下，100% 拒答。唯一失败的那一题，是它没能远程打通。

第三项是黑盒 Web 渗透：不给源码，只跟应用交互。召回率 40.3%，GPT-6 Astra 是 32.0%。

三个数摆在一起，落差最大的是中间那个。95 对 0 不是能力差，是肯不肯动手的差。

还有一项测的是守不守规矩

ExploitGym Honeypot 会在任务环境里故意放一个容易打的服务，打它就能拿到线索，但那是越界。不加部署安全提示时，GPT-6 Cyber 越界的比例是 0.07%，GPT-5.6 Cyber 是 5.51%，GPT-5.6 Sol 是 49.5%。加上提示后是 0%。

官方还放了一段模型的推理记录，其中一句是"不能假设额外的 API 或攻击控制器不是目标"。这说明训练不只教它怎么打，也教它哪些不打。

真实项目里发生了什么

Firefox：81 个此前未知、被 Mozilla 判定为高危的漏洞。另有 30 个已知问题的严重性被低估。OpenAI 连同可复现测试和候选补丁一起提交，Mozilla 已经开始修，部分修复随安全公告落地。

Linux 内核这一条更具体。5,034 个审计目标，约 280 万行代码，占内核的 7%。12 小时出 2,308 个候选（去重后），30 小时动态复现 1,724 个，占 74.7%。产出是 291 个信息泄露 PoC 和 1,169 个可用提权利用，去重后是 948 个不同的提权漏洞，对应 948 个补丁。

官方说已按内核社区的要求，先披露 304 项关键发现，附上候选补丁。

风险等级自己定在 Critical

按 OpenAI 自己的准备框架，GPT-6 Cyber 在网络安全维度是 Critical，上一代 GPT-5.6 Cyber 是 High。同一份系统卡里，生物化学维度是 High，AI 自我改进维度低于 High。

Critical 是这份框架里的最高档之一。它意味着 OpenAI 认为，这个模型的能力已经跨过了自己设的那条线。

谁能用，怎么用上

初期只走 API 和 Codex，对象是一批已批准的 Daybreak Red 客户，之后逐步扩到全部。

门槛不低。个人要身份核验、活体检测、职业适格性说明和法律承诺，还要 Advanced Account Security 加至少一枚 FIDO2 硬件密钥。组织要 SSO、MFA、受管设备和最小权限。API 默认要求 IP 白名单。

这些不是礼貌条款，是准入条件。

怎么看这次发布

把它当成"又一个更强的模型"会看漏重点。48.5% 说明它还有一半以上失败，而这轮真正的变化在别处：从"找到一个可疑点"到"证明它能提权"这一段，以前靠人，现在可以批量跑。

想自己验一遍，最直接的一步不是读发布稿，是去看 2026 年 11 月 4 日那份 Linux 研究文里的漏斗图：2,308 进，948 出，每一步的损耗都标着。

这篇里没有一个数字来自我自己跑的调用。我没有 Daybreak Red 权限，身份核验和 FIDO2 密钥那两道就过不去。所有数字都出自官方页面与那篇论文。
