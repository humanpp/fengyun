【正文】
这两天国内两家头部厂商先后在开源基座上落子：2026 年 11 月 4 日，腾讯发布 Hy4 并称近期开源模型权重；11 月 5 日，百度把文心 5.5 Flash Base 的权重放上了 Hugging Face。

一个已经能下载，一个还在"近期"

百度的动作是完整的。ERNIE-5.5-Flash-Base 是稀疏 MoE，总参数 2800 亿，每个 token 激活 140 亿，33.5 万亿 token 从零预训练，训练上下文最高 128K，微调与推理支持 1M tokens。权重和 LICENSE 文件都在页面上，任何人都能拉。

腾讯的动作还差一步。11 月 4 日 Hy4 发布时，官方给的是一句承诺：权重和系统卡片会在近期放出。四天过去，四个主流权重渠道里都还没有正式版的身影，许可证同样空着。

拿同门做对照会更清楚：Hy4 的预览版走的是另一条路，8 月 28 日发布当天权重就挂了出来，用的是 Apache 2.0。同一家公司、同一个系列，一次当场放，一次预告放。

这个差别对试用者无所谓，对企业采购是决定性的——没有权重，就没有本地部署，也没有微调。

两个模型卖的不是同一样东西

这里有个容易读错的地方。百度这次放出来的权重，官方写得很直白：未经中训练与后训练，停在预训练结束那一刻。它的定位是领域适配、指令微调和强化学习研究的起点，不是一个开箱能聊天的助手。

腾讯 Hy4 走的相反方向。它在预训练和后训练上显著扩展了规模，首次引入视觉理解与电脑操作，服务的是 WorkBuddy、CodeBuddy、元宝这些要立刻投入使用的产品入口。

一边交付"机器和图纸"，一边交付"成品的服务"。这不是谁高谁低，是两种成本结构。

买基座的人，图的是省掉从零预训练那一段。33.5 万亿 token 的预训练开销不会公开，但可以从规格反推量级：280B 总参数的权重，BF16 下就是几百 GB 的下载量，还有配套的算力。这条路原来只有少数几家走得通，现在多了一个能自己动手的起点。

买 API 的人，图的是明天就能用上，代价是能力边界、价格和可用性都握在别人手里。价格说调就调，权重说不放就不放。

所以"企业选择智能体底座的选项进一步增多"这句话要分两半读：能自己部署的那一档确实多了一个选项；只想调 API 的那一档，选项本来就在，变的是报价单。

质疑的那一面也该摆出来

第一，两份榜单的位次都值得留一分余量。腾讯引用的 Agent Arena 榜单，官方口径是总榜第 13 名、开源模型第一；另有聚合记录写作第 14 名，预览版第 25 名。两者差一位，本文不替它裁定哪一个更准。

第二，自主评测不能当独立结论。腾讯官网给的金融盲测成绩是 579 个真实任务里综合 3.04 分，高于 DeepSeek-V4.1-Flash-1017 的 2.97、Kimi K3.1 Pro 的 2.68 和 GLM-5.3 的 2.68；参与盲测的 213 名金融从业者中，组织方是腾讯混元团队联合腾讯金融科技。评测由发布方及其合作方组织，题目与判分方法没有公开，这类成绩可以看，不能当定论。

第三，百度的许可证不是标准开源协议。文件名是 ERNIE 5.5 Flash Base Model License Agreement v1.0，百度自定。第三方记录提到其中包含许可地域与再分发的限制，本文没有逐条核对原文，采购前应自行读一遍 LICENSE。

第四，十倍的计量口径没交代。腾讯公告只说"WorkBuddy 已进行十倍扩容"，没说十倍的是什么。

一句话判断：这一轮真正变化的不是模型能力榜单，是基座的可得性——从"只有少数几家能自己从零训"，变成"两家头部厂商把预训练终点放出来，你要不要接"。
