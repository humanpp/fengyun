1. 同一张官方自测表里，赢了五项却输了四项
2. 多视角画质七项都占优，蒸馏版却在两项上退步

【正文】
同一张官方自测表上有三个 DOVER 技术分：基线 8.56，Cosmos3-Nano-Transfer-Auto 9.01，蒸馏版 Cosmos3-Nano-Sim-Auto 7.30。蒸馏换来的是流式生成，代价就写在这三个数里。

先看这批数字是怎么测的

评测在 720p 下做，Transfer-Auto 用 guidance scale 3，蒸馏版用 1，基线 Cosmos-Transfer2.5-2B Multiview 用 3。模型卡里另有一句：基线使用的是不同的 prompt。这句话决定了这批分数只能逐项看方向，不能拿来整体排名。

四个指标各看一件事

帧 FID 比的是单帧特征分布，视频 FVD 比的是整段视频的分布，两项都在量生成结果离真实数据有多远。DOVER 是视频质量打分类指标，偏向人眼观感。时序 Sampson 误差与跨视角 Sampson 误差算的是几何：前者看同一路相机相邻帧的点对不对得上，后者看不同相机在同一时刻对不对得上同一处结构。

七项里方向一致

帧 FID 从基线的 61.9 降到 45.5，视频 FVD 从 772 降到 488，DOVER 从 8.56 升到 9.01，时序 Sampson 误差从 0.530 降到 0.473，邻帧余弦均值从 0.885 升到 0.906，跨视角 Sampson 两视角从 2.51 降到 2.01，五视角从 2.07 降到 1.63。

蒸馏让回去的两项

蒸馏版的帧 FID 48.6 仍然好于基线 61.9，视频 FVD 480 也好于 772，可 DOVER 掉到 7.30，比自己的教师版本低 1.71，比基线低 1.26。跨视角 Sampson 五视角从 1.63 回到 2.24，反而比基线的 2.07 更差。

两组结果方向不同并不矛盾。分布距离与观感分靠海量数据和生成能力撑起来，蒸馏压缩的是去噪步数，受影响最大的是每块累积下来的几何误差。差 1.71 的 DOVER 背后，是每块只走四步的代价。

换到给一张图再生成视频这一档，方向没有变。蒸馏版的帧 FID 是 33.6，对基线的 41.9；视频 FVD 是 325，对 383；DOVER 是 7.51，对 8.22；跨视角 Sampson 五视角是 2.09，对 1.98，落后的还是这一项。两档合起来看，蒸馏的短板是稳定的，不像是一次测量上的偶然。

激光雷达这六项

雷达一侧，Transfer-Auto 对 LidarVerse 基线的俯视分布 JSD 从 0.116 降到 0.0401，Fréchet Utonia 距离从 44.8 降到 12.8，目标支撑召回从 0.788 升到 0.885，生成雷达对真值的目标检测 F1 从 0.200 升到 0.237。车辆时序一致性比是 2.53 对 2.51，这一项落在基线后面。

机器人这一侧

Sim-Bimanual 在 AgiBot-World 上的 PSNR 是 14.4138 dB，对 DreamDojo 2B 的 12.1016 dB 与 14B 的 12.3561 dB；SSIM 是 0.6839，对 0.6405 与 0.6635。换到相机导航的 PAI-Bench-G，画质 73.9099 高于 LingBot-World 2.0 的 65.3577，绝对平移误差 4.7072 却不如对方的 4.1698，画得好不等于走得准。

同门对照也不能漏。Sim-Transfer 对比自家基座 Cosmos3-Nano，控制跟随四项全部变好：分割 mIoU 从 0.643263 到 0.73776，模糊 SSIM 从 0.855906 到 0.88665，边缘 F1 从 0.214024 到 0.340696，深度 SI-RMSE 从 0.842346 降到 0.619426；DOVER 反而从 10.359606 掉到 10.175942。

还有一层边界要交代。这些分数来自官方自测，跑在官方发布的驾驶仿真评测数据集上，第三方复现还没看到。指标自身的口径也有限，邻帧余弦均值只用无真值的画面算，官方在注释里写明：画面冻住同样能拿高分，所以它单独不能证明动作是真实的。

把这批数字当选型依据之前，记得先用同一套 prompt 在自己的数据上复现一遍，重点看跨视角那两项。赢的集中在分布距离与视觉质量，输的集中在时序一致性和跨视角几何，蒸馏会把后者放大。
