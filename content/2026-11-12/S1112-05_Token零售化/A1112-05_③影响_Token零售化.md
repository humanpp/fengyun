【正文】
同一张月卡，淘宝卖 19.5 元，官网卖 60 元。这个价差就摆在商品页上，谁都能看见。

2026 年 11 月 4 日，中国青年报记录了一个变化：今年双 11，电商平台的货架上多了一类新商品——Token。天猫把它设成独立品类，京东把它放进 AI 软件充值馆。两家都不是从零开始：9 月起第一批大模型公司就已经入驻，天猫上线了 AI 空间站 Token 充值中心，在淘宝搜 Token 就能进。

这看起来只是一条渠道消息，但它牵动的是定价权归谁。

比价变成默认动作

过去 Token 的价格只出现在一个地方：厂商自己的 API 计费页。改价的方式是更新文档，用户看到的时间就是生效时间。

摆上货架之后，价格进入一个能被横向对比的页面。科创板日报 11 月 11 日的记录里，千问 AI 月卡 Lite 淘宝价 19.5 元、官网价 60 元；Essential 是 39.5 元对 120 元；Standard 是 139 元对 180 元。同一时期，MiniMax 三款月卡全 5 折，智谱周卡 5 折起，Qoder 月卡 3.3 折。

折扣本身不新鲜，新鲜的是它出现在同一个页面上。厂商之间的价差，从此不再只是圈内话题。

涨价也会留下痕迹

反过来推，零售化对厂商还有一层不易察觉的约束：打折是公开的，收回折扣也会是公开的。

科创板日报采访的一位内容作者金多多（化名）把这层变化说得更直接：过去定价权在厂商手里，API 价格挂在开发者文档里；现在套餐被放在同一个电商页面，比价压力从开发者圈层扩散到了普通消费者。他的原话是，前者是供给端逻辑，后者是需求端逻辑。

被影响的不只是买的人

至少三类人会被这件事往下推。

第一类是重度个人用户。包月和按量的价差摊开在同一个页面上，选择从用哪家变成买哪种计费方式。中国青年报引百联咨询创始人庄帅的说法，电商平台提供了更低门槛的购买方式，用户可以集中查看不同厂商的产品和套餐，不必逐一登录官网、查找计费规则和比较价格。

第二类是做小工具和小应用的开发者。他们的成本结构是 Token，而终端用户对 Token 价格有了直觉之后，你的定价为什么比别家贵，会变成一个新问题。

第三类是想进这个渠道的厂商。9 月开出的入口，现在成了流量位；进不进、给多少折扣，会变成渠道预算的一部分。庄帅的定性更谨慎：这是平台占位 AI 新品类入口的尝试，而且他同时提醒，目前电商渠道的价格优势还不明显。

还有一层不在正文里显形

Token 被摆上货架，还顺手暴露了一个更基础的问题：它至今不是一种能按标准比价的商品。

中国青年报引国家发改委中国宏观经济研究院杨祥雪、魏巍的说法：不同平台对同样文本的词元计数结果存在显著差异，同一平台不同模型的分词规则也不统一；兑换比例、折扣体系、免费额度这些参数，设置和变更完全由平台单方操作，改价可以只通过更新 API 文档完成。

这意味着货架上的价格可比，货架上的单位却不见得可比。同样是 100 万 Token，在不同分词规则下对应的文字量并不相同。

判断

Token 上货架，短期看是一次促销，长期看是一次定价权的迁移：从厂商单方面更新文档，变成在公开页面上接受比价。

买的人以后可以像买会员一样比价，但要分清买到的是额度还是会员时长，这两者在页面上是两种商品。

厂商那边，折扣和涨价都会留下公开痕迹。建议把渠道价当成产品的一部分来定，别当成一次性的活动价。
