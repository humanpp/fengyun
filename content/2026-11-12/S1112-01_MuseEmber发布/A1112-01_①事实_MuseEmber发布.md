【正文】
0.10 美元。这是 Meta 给 Muse Ember 定的每百万输入 token 价格，输出是 0.50 美元。

2026 年 11 月 9 日，Meta 发布这款自称 Muse 系列最小、最高效的模型。它的定价不是唯一的卖点，但一定是最容易被记住的那个：同样一百万输入 token，Claude Haiku 5.5 和 GPT-6 Luna 也都是 0.10 美元。三家的标价撞在了一起。

先看它是什么。Muse Ember 的 API 标识是 muse-ember-1.0，通过 Meta Model API 的 Responses、Chat Completions、Messages 三个端点调用，也在 Muse Code、Google Cloud、Oracle Cloud 上线。上下文窗口 1,048,576 token，单次输出最多 524,288 token。输入支持文本、图像、视频、音频和 PDF，输出只有文本。权重不公开，参数量官方没有披露。

三家都有一条涨价线

0.10 和 0.50 只对不超过 20 万 token 的提示有效。超过这条线，输入涨到每百万 0.30 美元，输出涨到 1.50 美元，缓存读价从 0.004 美元涨到 0.012 美元。

三家模型都有自己的分界点，位置和跳幅各不相同。Claude Haiku 5.5 卡在 10 万 token，过了就是 0.50 美元与 2.50 美元；GPT-6 Luna 卡在 27.2 万，过了是 0.20 与 0.75；Muse Ember 卡在 20 万，过了是 0.30 与 1.50。按 VentureBeat 核对，Ember 的高价适用于整个请求，包括输出部分，不只是超出的那一段。

这条规则对 Agent 特别要紧。Agent 每一步都要把历史重发一遍，上下文是滚动增长的，一次长任务很容易把最后几步推进高价档。还有一处反直觉：提示超过 27.2 万之后，GPT-6 Luna 的 0.20 与 0.75 反而比 Ember 的 0.30 与 1.50 便宜。Ember 的便宜是有前置条件的。

它还有六个推理档位，从 minimal 到 max，默认停在 max。这个默认值很关键：档位越高，思考 token 越多，账单越往输出那一侧偏，而输出单价是输入的 5 倍。

分数贴得很近，成本差得远

在 Artificial Analysis 的智能指数上，Muse Ember 最高档拿 36 分，Claude Haiku 5.5 最高档也是 36 分，未取整分别是 35.8 和 36.2。同一份评测里，Ember 最高档跑完一个任务的平均成本约 0.14 美元，xhigh 档是 0.12 美元；Haiku 最高档是 0.41 美元，xhigh 档是 0.25 美元。按标价估出来的“约三分之一”，比的就是 0.14 和 0.41——这是估算，不是账单。

但分项一拆开就没那么齐。FrontierCode 2.0 评的是改动能不能被维护者合并，Haiku 34.9 分，Ember 27.2 分。Terminal-Bench 4.0 上 Ember 40.9、Haiku 39.2，看着赢了 1.7 个点，可两家用的脚手架不同：Ember 跑在 mini-swe-agent 上，Haiku 跑在 Claude Code 上。跨脚手架比出来的分差，不能当排名用。

还有一层得交代。Meta 自己的评测报告写明，对竞品的复跑是“尽力而为”，提示词与工具未必调到最优。也就是说，表里那些“领先”有一部分可能来自对方没被调好，而不是自家更强。

AutomationBench-AA 是差距最大的一项。Meta 自测口径下，模拟 657 项业务工作流，按全部目标达成且不违规计算，Ember 37.8 分，Haiku 13.9 分，Luna 20.2 分。Artificial Analysis 另有一个按单个目标给分的口径，Ember 是 68.1 分。两个数由不同方按不同规则算出，不能当成同一张表的两列。

它被放在流水线的哪一格

Meta 自己的分层写得很直白：Muse Wonder 做最难的问题，Muse Spark 做编程与 Agent 工作流，Muse Ember 跑那些一天重复几百遍的步骤——工具调用、路由、抽取、长文档解析。Ember 是第一个用 Muse Wonder Full 训练出来的模型，不是拿来当旗舰用的。

这解释了价格为什么能这么低，也解释了它为什么在某些项上敢于落后。跑量的一格不需要全能，需要的是每一次都够便宜、够稳定。

判断

Muse Ember 争的不是“最强”这个位置，是“最划算的重复劳动”这个位置。它真正的卖点不是 0.10 美元，而是这个价格对应的那类任务：边界清楚、有验收标准、错了能重试。

做 Agent 的团队，先别按单价迁移。把近一周的调用日志拉出来，看有多少请求的提示超过 20 万 token，再看失败重试的比例。这两项决定了账单价和标价差多远。挑一个每天跑几百次的子步骤试一周，比看任何跑分都准。
