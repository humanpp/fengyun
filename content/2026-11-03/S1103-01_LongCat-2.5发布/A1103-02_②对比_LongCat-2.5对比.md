【正文】
美团给 LongCat-2.5 出了一张很大的评测表：40 项基准，8 个对照模型。

对着这张表看下来，最准确的描述是：它大致落在 Claude-Opus-4.8 和 Claude-Opus-5 之间，个别项目上探到 Opus-5 之上，个别项目退到 Opus-4.8 之下。

先把评测表的可信度说清楚

官方原文有一句话很关键：对比模型里带星号的分数取自公开技术报告、博客或官方榜单，不带星号的是美团自测，仅供参考。

这带来两个问题。

一是来源不齐。比如 Terminal Bench v4.0，GPT-5.5 那一格是空的，因为没找到公开分数。再比如 VideoMME，Claude-Opus-5 那格也是空的。

二是可比性有限。带星号的分来自各家自己的技术报告，测试条件、harness、随机种子都可能不同。把自家测试和别人的公开分数并排放，本身就是一种宽松的比较。

所以下面这些对比，看趋势可以，看精确排名要谨慎。

赢在哪几项

真正超过 Claude-Opus-5 的项目不多，但有几个值得一提。

LongCatClawBench FORTE 上，LongCat-2.5 是 83.3，Claude-Opus-5 是 82.6，赢 0.7 分。这个基准是美团自建的。

AutomationBench v1.0.6 上，51.8 对 50.3，赢 1.5 分。这个基准用的全部 600 道公开题加官方评测代码。

BrowseComp 上，91.9 对 90.8，赢 1.1 分。

3DCodeBench 文本转 3D 上，55.4 对 54.3，赢 1.1 分。

ResearchRubrics 上，81.0 对 72.9，赢 8.1 分。这是差距最大的一项。

输在哪几项

Terminal Bench v4.0 是差距最刺眼的一项：38.5 对 53.9，输 15.4 分。

Program Bench 上，25.5 对 37.0，输 11.5 分。

NL2Repo 上，60.5 对 75.3，输 14.8 分。

SWE Atlas 的 Test Writing 上，47.8 对 62.2，输 14.4 分。

MCP Atlas 上，83.1 对 85.8，输 2.7 分。

把这几项放一起看，规律很清楚：凡是需要在真实代码库里连续操作、根据中间结果反复修正的任务，差距就明显。Terminal Bench 考终端多步操作，Program Bench 考完整程序构建，NL2Repo 考从自然语言到仓库级代码，都是这个类型。

反过来，检索类、问答类、单轮推理类的任务，差距就很小甚至反超。

和 GPT-5.6-Sol 比是另一种局面

如果换成 GPT-5.6-Sol 做对照，LongCat-2.5 的表现更均衡。

BrowseComp 91.9 对 90.4，AutomationBench 51.8 对 45.8，HLE w/ tools 63.1 对 58.0，ALE v1.1 38.5 对 30.3，ResearchRubrics 81.0 对 74.2，SkillsBench 63.3 对 54.1，Terminal Bench v4.0 38.5 对 37.3，这几项都领先。

落后明显的是 NL2Repo 60.5 对 56.8 之外的部分，以及 DeepSWE v1.1 64.6 对 72.7、VideoMME 85.2 对 89.5、Claw-Eval 78.3 对 79.5。

也就是说，面对这一代西方模型里的中档选手，LongCat-2.5 是互有胜负；面对 Opus-5 这个顶尖选手，是多数落后、少数反超。

一个容易忽略的细节

LongCat-2.0 的分数在同一张表里。

对比两代：Terminal Bench v4.0 从 3.0 到 38.5，Program Bench 从 2.5 到 25.5，NL2Repo 从 40.9 到 60.5，AutomationBench 从 15.8 到 51.8。

这个提升幅度比"和谁比"更值得看。AutomationBench 三倍多的增长，说明这一代的主力投入确实放在了智能体任务上。

但 Terminal Bench 从 3.0 到 38.5 这个跳跃也要冷静看。3.0 这个数字低得反常，更像是上一代在这个 harness 下基本跑不动，而不是能力真的有 12 倍差距。

视觉部分没有想象中强

这一代官方重点讲了视觉 token 离散化，但视觉类 7 项里，LongCat-2.5 对 Opus-5 只赢了 2 项。

3DCodeBench 赢 1.1 分，CharXiv-RQ 赢 0.9 分；Vision2Web 输 1.6 分，PosterBench 输 4.9 分，MathVision 输 1.3 分，VideoMME 输 4.3 分，LongCatClawBench-MM 输 1.0 分。

PosterBench 和 VideoMME 的落后值得注意。海报生成和视频理解是视觉能力的硬指标，这两项没跟上，说明视觉离散化这条路在训练效率上的收益，暂时还没完全转化成能力优势。

一句话判断：LongCat-2.5 是一次扎实的迭代，在智能体和检索类任务上已经能和第一梯队对话，但在长链条代码工程和视频理解上还有明显短板。

选型建议：如果你的任务是检索、问答、结构化数据分析和中等长度的自动化流程，它现在就能用，价格还便宜；如果要跑仓库级重构或者长视频理解，再等等。
