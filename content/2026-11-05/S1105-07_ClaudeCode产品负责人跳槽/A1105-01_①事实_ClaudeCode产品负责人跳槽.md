【正文】
2026 年 10 月 30 日，是 Catherine 吴在 Anthropic 的最后一个工作日。11 月 3 日，她把自己的离开写在了社交平台上。11 月 5 日，同一个人宣布加入 OpenAI，负责核心产品的产品管理。三天，三件事，中间没有空档。

她在中国开发者圈子里更常被叫作 Cat Wu，职位是 Claude Code 的产品负责人。

这条人事消息有两家媒体给出了完整版本。Business Insider 的报道确认 OpenAI 已经录用，Anthropic 则拒绝置评。报道里有一句关键的话，来自 OpenAI 的一位代表：她将和负责企业产品的尼克·特利协作，和负责消费级产品的阿什利·亚历山大协作，向蒂博·索蒂奥汇报。索蒂奥分管核心产品与平台，Codex 在他手下。

为什么要看汇报关系

因为这是目前唯一确定的部分。她入职帖里的原话是"加入 OpenAI 负责核心产品的产品管理"，没有写自己管哪一块。

OpenAI 也没有补上。官方未公布具体分管产品，这就是眼下这件事的边界：位置给了，职责范围没给。她可能偏向 Codex，也可能偏向面向企业的 ChatGPT 版本，从公开信息里推不出来。

她自己在帖子里给了方向感。按外媒引述，她的表述是希望大家一起做出"能支持你和你的团队的智能体，同时把控制权留在你手里"。这句话很虚，但和 OpenAI 最近几个月的产品动作对得上。

她在 Anthropic 管的并不止一条线。除了 Claude Code，她还负责 Cowork，那是面向非程序员的办公产品，用的是同一批模型。也就是说她过去两年练的是"把写代码的助手推到不做代码的人手里"这件事。

那两周里还走了两个人

单看一个人，这只是硅谷常见的人事流动。放到时间轴上看就不一样了。

10 月 23 日，Claude Code 桌面客户端的作者安东尼·莫里斯宣布离开。10 月 24 日，负责核心工程的塔里克·希希帕尔也宣布离开。10 月 30 日，她走了。三名核心成员，两周之内。

三个人的告别文本都体面，都肯定了公司，没有一个人说走了是因为不满。Anthropic 也没有对任何一次离职给出解释。外媒提到的时间关系就是"赶在上市之前"，但这只是时间上的并列，不是原因。

还有一条容易被忽略的旧事。2025 年 7 月，她和 Claude Code 的创造者鲍里斯·切尔尼一起离开过 Anthropic，去了 Cursor，两周后又回到 Anthropic。据 The Information 当时的报道，两人是同时走、同时回。这一次只有一个人回头，另一个留在了原地。

公司这边在发什么

把镜头挪开一点。2026 年 11 月 2 日，Anthropic 更新了招股书。按文件，第三季度营收 169.6 亿美元，上年同期 13.8 亿美元，同比涨了 1127%。单季调整后营业利润 25 亿美元，调整后营业利润率 15%；按会计口径算，营业亏损 5.67 亿美元。当季净亏损 233 亿美元，其中很大一块来自可转换工具和衍生负债的公允价值变动，不是经营现金流出的那部分。

同一份文件里有一组和她直接相关的数字：企业客户里没用 Claude Code 的，人均月支出低于 75 美元；用了 Claude Code 的客户中，消费额最高的 5%，人均月支出大约是前者的 20 倍。

一个工具能把客户的钱包撬到 20 倍，这解释了她的分量，也解释了 OpenAI 为什么要在这个时候把人挖过去。

我自己的判断有三条

第一，这条消息最硬的不是人事本身，是流程速度。周五离职，周二公布，周三入职，中间没有休息期。她自己被问到要不要先放个长假，回答是"post agi！"。

第二，可验证的部分已经很足。她的社交账号简介改成了"core products @ openai, prev: claude code @ anthropic"，职业社交平台上的职位也更新成了 OpenAI。这两处是她自己的账号，比任何转述都硬。

第三，不确定的部分不要猜。她为什么走、拿的什么条件、Codex 会不会因此改路线，公开信息到不了这一步。谁要是给你一个完整的故事，多半是编的。

如果你在选工具，这件事暂时不用影响你的决定。Claude Code 的定价、额度、模型都没变，继任者官方也还没公布。真正值得盯的是两件事：Anthropic 多久公布接任者，以及 OpenAI 核心产品线在接下来的版本里，界面和默认行为有没有根据非程序员的使用习惯改动。
