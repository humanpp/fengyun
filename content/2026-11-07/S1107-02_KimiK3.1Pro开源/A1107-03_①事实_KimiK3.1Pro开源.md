【正文】
2026 年 11 月，Kimi K3.1 Pro 的模型权重放了出来。这条消息里最硬的一个数字是 3 万亿级，官方对参数规模的表述就这一句，没有小数，也没有单独拆出激活参数。

先把三件事摆清楚：权重开源，模型文件可以下到自己的机器上；参数规模到 3 万亿级；上下文长度 100 万 tokens。三件事同时成立，素材才把这次开源称作这一时段开源模型尺寸上的一个重要节点。

还有两组能查到的信息，一组是价格，一组是开放范围。API 输入 13 元 / 百万 tokens（未命中缓存）、输入 1.3 元 / 百万 tokens（命中缓存）、输出 68 元 / 百万 tokens，币种人民币，官方页面没标成限时价。开放范围是网页、App、Kimi Work、Kimi Code 与 API，加上这次放出的权重。

开源之后有两条路并存：能调接口的调接口，要私有化的自己部署。两条路的账不一样，接口按 token 计费，自建按卡和电费算。官方没给权重体积，但这条账还开不完整，缺的是权重体积这一项。

3 万亿级，先看装不装得下

参数到这个量级，第一道关不是跑分，是显存。一份权重放不进一张卡，必须切成多份铺到多张卡上，卡间通信效率直接决定实际速度。官方没给单卡显存占用，也没给切分建议，想自建的人第一步是自己算这笔账：几张卡、什么互联、切几份。

这一步算不下来，后面的讨论都没意义。3 万亿级是这条消息的主语，它同时是一张账单；换算成排队等卡的月数，它比跑分更早决定项目能不能开。

它的强项不在总分

官方评测表里四项成绩能说明位置。Terminal-Bench 4.0 是 65.7，Claude Opus 5.5 为 66.4，GPT-6 Astra 为 58.2。SWE Marathon v1.1 是 51.7，两个对手分别是 46.3 和 42.5。HLE-Full 带工具是 70.0，对手是 67.7 和 57.2。BrowseComp 是 92.1，对手是 90.8 和 91.5。

四项看下来，对 Claude Opus 5.5 是三胜一负：终端操作类落后 0.7 分，长程代码、带工具解题、网页调研三项分别领先 5.4 分、2.3 分、1.3 分。对 GPT-6 Astra 四项全胜。这四项都是官方自测，对手分数取自各自博客或榜单最大值，条件不同，只能读量级。四项分别对应终端操作、长程代码、带工具解题、网页调研四类任务，官方全表有 47 项，这里只取这四项，是因为它们最接近日常在干的活。

版本关系也值得记一笔：K3.1 是 K3 的后训练版本，是 K3.1 系列的第一个模型；同代还有 Highspeed 版，输出速度约 2 至 3 倍，价格是 2 倍。这次开源放出的是 Pro 这一支的权重。

100 万 tokens 的那一档

上下文给的是 100 万 tokens，官方写成一个整数档，没有说明是否由更短的训练长度外推得来，也没有给长上下文下的召回衰减数据。材料越厚，这一档越有用；稳不稳，要等第三方测。

一句话落定

这次开源的分量压在尺寸档位上，不在分数排名上。按素材的说法，这是这一时段开源模型在尺寸上的一个重要节点；档位被推上去，后面跟进的模型会拿它当参照。

想自己跑的人，先查显存账与并行方案，别先下模型；只想用能力的，上面三档价格已经能算出成本，不必等自建。
