【正文】
2026 年 10 月 30 日，商汤科技开源了 SenseNova Loop-9B-Preview。官方称这个 9B 级的 Looped Transformer 媲美 27B 参数大小的模型。具体证据是三项基准：WorkBuddy Bench、RaccoonPPT Bench、AutomationBench，超过 Qwen3.5-27B。商汤在官方博客里把它称为面向下一代模型架构的前沿探索，给社区提供 9B 级 Looped Transformer 的开源实践。IT之家 11 月 1 日的报道，标题里带着宣称两个字。

循环层是怎么回事

模型一共 32 个解码层。第 0 到 3 层照常跑，第 4 到 27 层这 24 层共享权重跑两遍，再由第 28 到 31 层输出。一次前向传播做 56 次层计算，存的却只有 32 层权重。官方的说法是引入循环计算、扩展模型的有效计算深度。GitHub README 的写法是：总参数约 9B，推理参数约 14.6B。

同一套权重跑两遍，信息会不会搅在一起？商汤给模型配了 mHC，全称流形约束超连接：两条残差流，学习到的映射控制每一层怎么从流里读、怎么写，流与流之间的混合用 Sinkhorn 归一化约束，迭代 20 次。官方称这是用多路残差连接和受约束的信息混合，增强特征交互、稳住信号传播。注意力层也是混合的，每四层一组，三层的线性注意力配一层的满注意力，循环边界对齐完整的四层组。

消融数字给了底气

官方对 mHC 做了消融实验，IT之家转录了两个数：用上 mHC 后，GPQA Diamond 提高 4.42 分，TeamBench 提高 13.34 分。前者是复杂推理基准，后者是商汤自家的多步智能体基准。这份评测集里，RaccoonPPT Bench 的名字本身就指向商汤自家的办公产品小浣熊。官方说后续还要探索 DSA、自适应迭代次数这些机制。

架构参数全部公开：隐藏维度 4,096，前馈维度 12,288，词表 248,320，满注意力头 16 个、KV 头 4 个；训练序列最长 262,144 tokens；主干 BF16，mHC 路由参数 FP32。输入是文本和图像，输出是文本。

开源了，但有门槛

许可证是 Apache 2.0，权重挂在 Hugging Face 和 ModelScope，微调脚本和训练指南一起给了，LightLLM 有四卡部署示例。仓库 examples 目录里放着现成演示：教师节、冰岛、巧克力三套 PPT，一段月球轨道仿真动画，一套能源分析图表。

推理加速上，MTP 已经可用，DSpark 和 DFlash2 还在训练。但推理本身还谈不上即装即跑：vLLM 要用 PR #64832 的版本，SGLang 要用 PR #47281 的版本，Transformers 锁 5.18.0，PyTorch 要 2.11.0 CUDA 13.0。

我把 README 和模型卡逐段读完：技术报告一栏写着 TBD，还没发布。Hugging Face 页面自动标注的参数是 10B，和 README 的约 9B 对不上，两个口径我都记进了素材卡。上月下载 2,704 次。

我的判断

媲美 27B 是官方宣称，证据是三项办公与智能体基准超过 Qwen3.5-27B，分数还藏在图表图片里。但方向本身值得记录：不加参数，把中间层多跑一遍换有效深度，消融数字说明 mHC 不是装饰。真要用这个 9B，等两件事：技术报告发布，循环实现合进 vLLM 和 SGLang 的正式版。在那之前，它更适合想研究下一代架构的人先跑起来试试。只想尝鲜的话，Hugging Face 上已经有 10 个量化衍生版本，参数更小，普通显卡也能先跑着看。
